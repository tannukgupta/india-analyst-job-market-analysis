# India Analyst Job Market Analysis

## 📊 Project Overview

An end-to-end data analytics project analyzing analyst job postings in India.

The project uses job-market data collected through the Adzuna API to identify:

- Which analyst roles are most in demand
- Which Indian cities have the highest concentration of analyst jobs
- Which technical skills employers mention most frequently
- Salary patterns across analyst job categories
- The most important skills for Data Analyst positions
- Geographic differences in analyst job opportunities

The project covers the complete analytics workflow from API data collection and data cleaning to exploratory analysis and an interactive Power BI dashboard.

---

## 🎯 Business Questions

This project answers the following questions:

1. Which analyst job categories have the highest demand?
2. Which Indian cities have the most analyst job opportunities?
3. Which skills are most frequently mentioned in analyst job postings?
4. What is the typical advertised salary for analyst roles?
5. Which analyst categories have the highest median advertised salaries?
6. What skills are most important for Data Analyst positions?
7. How are analyst job postings distributed across years?
